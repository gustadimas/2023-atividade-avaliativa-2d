# Atividade Avaliativa (plataforma 2D)

Atividade da faculdade de set/2022 a jun/2023. Publiquei anos depois (nov/2026) e não atualizei nada.

Atividade avaliativa de motores 2D. Juntei várias mecânicas de plataforma em três cenas (`SampleScene`, `ShootingRange` e `Traps`): plataformas seguindo waypoints, plataformas que caem, arma de bola de fogo, alvos, bombas e um teste de raycast. Alguns scripts são de setembro de 2022 e vieram de projetos anteriores.

## Como abrir

Abra a pasta do repositório pelo Unity Hub (Add project from disk). Usei o Unity 2021.3.15f1. A pasta Library não está no repositório; o Unity gera de novo na primeira vez que abre.

Outros projetos da faculdade: [projetos-da-faculdade](https://github.com/gustadimas/projetos-da-faculdade)
